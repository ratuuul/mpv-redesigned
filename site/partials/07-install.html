06 Install

One command, then it just plays.

The installer backs up whatever it finds, deploys the configuration and starts mpv once to prove the file parses. It never asks for administrator rights, and it never writes outside your own profile.

windows · powershell

irm https://raw.githubusercontent.com/ratuuul/mpv-redesigned/main/install.ps1 | iex

linux · bash

curl -fsSL https://raw.githubusercontent.com/ratuuul/mpv-redesigned/main/install.sh | bash

Run it from Windows PowerShell 5.1 or PowerShell 7, not from cmd. A preview that changes nothing at all is one switch away.

  1. 01 The repository archive is downloaded and unpacked to a temporary folder.
  2. 02 If mpv is missing and scoop is not installed, mpv is unpacked locally and the user path is extended.
  3. 03 yt-dlp is downloaded into the configuration so the network hook finds it first.
  4. 04 An existing configuration is moved to a timestamped backup and the watch history comes along.
  5. 05 mpv is started once to confirm the configuration parses.

The bash installer mirrors the PowerShell one: it backs up whatever it finds, deploys the configuration into ~/.config/mpv, downloads yt-dlp and checks that the configuration parses.

  1. 01 Install mpv and yt-dlp from the distribution package manager, or let the installer point you at the right command.
  2. 02 Run the command above, or clone the repository and run bash install.sh from the clone.
  3. 03 Keep the yt-dlp options line in the master file, including the JavaScript runtime hint.
  4. 04 Start the player with a file, a link, or a folder to play everything in it.

uninstall and rollback

The uninstaller moves the configuration into a timestamped backup instead of deleting it, so the rollback path stays open. The player itself is left alone.
