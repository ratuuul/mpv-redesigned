02 What you get

Twelve things the default mpv never had.

Every entry below is a setting you can read in the repository, on a file that explains why it exists. Nothing is hidden in a binary, and every one of them can be switched off again.

The configuration is split by domain rather than by length, so a renderer option lives with the renderer options and a subtitle option lives with the subtitle options. The master file only includes the rest. Read one domain end to end and you have read everything that domain is able to do.
