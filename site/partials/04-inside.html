03 Inside the configuration

One tree. Every setting has a home.

The configuration is split by domain instead of by length. A renderer option lives with the renderer options, a subtitle option lives with the subtitle options, and the master file only includes the rest.

the tree, as deployed

deployed to the mpv configuration directory — the master file includes the rest

  1. A / Includes

    mpv.conf is a short master file that includes the five conf files. Nothing is set twice and nothing is set in two places.

  2. B / Reasoned options

    Every non-obvious line carries the reason it exists, in the comment above it. A setting nobody can explain is a setting that should not be there.

  3. C / One keymap

    input.conf is the only place a key is bound, and nav_shim.lua forwards the same bindings to either skin.

  4. D / Parked, not deleted

    The alternative skin lives in skins/modernz and is moved in by a single script. Exactly one skin is ever loaded.
