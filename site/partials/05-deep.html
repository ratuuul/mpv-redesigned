04 Deep dive

The six details that change the feel.

Six pieces of the configuration are worth reading closely, because they are the difference between an mpv you tolerate and one you keep open.

Deep dive 01

The idle photo background.

When there is nothing to play, mpv shows a black rectangle and waits. This configuration fetches a photograph instead, caches it locally and puts the prompt on top of it. The image is blurred and darkened enough that the text stays readable over it, and the next photograph is one key away.

  • Cached on disk, so the idle screen never waits on the network twice.
  • Keyword driven, and switched off completely with a single option.
  • The next photograph is fetched with Ctrl+Shift+K.

Deep dive 02

Double-click to resume.

Closing mpv and coming back later should not mean finding the file again. A double click on the window reopens the last media and resumes it at the exact position it was left at. The saved position deliberately ignores stray volume and mute changes, so a film never comes back at the wrong level.

  • A deliberately narrow list of what is restored: start, speed, pitch, tracks, delay and scale.
  • No modification time check, so remote files keep the position they were saved with.
  • Fullscreen moved to f, which leaves the double click free.

Deep dive 03

YouTube, as a real client.

A URL is not a file, and the default player treats it like one. Here the format menu lists the formats the server actually offers and switches between them without reloading the video. The subtitle menu lists every language the video carries, creator uploaded and auto generated, with a separate track for the secondary language.

  • Creator subtitles are pre-loaded as normal tracks, so the usual v key still works.
  • Sponsor segments are skipped with b, and the category list is configurable.
  • The stream you are watching can be downloaded at the quality mpv negotiated.

Deep dive 04

A subtitle pipeline, not a font size.

Subtitles are set in Geist Medium at 40, in a warm off-white, with a hairline outline and a soft shadow so they survive any background. The margin is forced, so the caption keeps the same distance from the bottom edge whatever is playing, and the window takes the shape of the video so the picture always fills it. The result reads as part of the picture rather than as a layer on top of it.

  • Fansub ASS files get a gentle restyle so they match plain text subtitles.
  • Two opt-in looks: a translucent panel, and shadow-only cinema subtitles.
  • Bitmap subtitles are softened rather than restyled.

Deep dive 05

Hardware decode, then Anime4K.

On an integrated GPU with shared memory the expensive part is the copy out of system memory, so the decode path is kept on the device. On top of that sits the full quality stack: EWA Lanczos for luma, spline36 for chroma, mitchell for downscaling, and anti-ringing so the sharpening does not ring. Every line here was measured on this machine before it was kept.

  • Anime4K line-art restoration applies itself to files whose path contains anime.
  • The shader cache is built ahead of time, so the first play does not stutter.
  • Vulkan output is one key away, with Alt+0, for an A and B comparison.

Deep dive 06

Controls that hover, then get out of the way.

The control bar and the timeline are translucent, and they stay on screen while the picture plays. The overlays are pointer driven: they appear where the mouse is and fade away when it leaves. The window stays interactive after a file ends, so the next one can be dragged straight in.

  • Centred seek, volume and speed overlays, drawn by the skin rather than by the player.
  • Seekbar thumbnails are pre-fetched while the pointer moves.
  • An info button opens the player statistics: codec, frames per second, bitrate, dropped frames.
