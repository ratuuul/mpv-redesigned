The six details that change the feel.

Six pieces of the configuration are worth reading closely, because they are the difference between an mpv you tolerate and one you keep open.

Deep dive 01

The idle photo background

When there is nothing to play, mpv shows a black rectangle. This configuration fetches a photograph instead, caches it locally, and puts the prompt on top of it. The image is blurred and darkened enough that the text stays readable, and the next photo is one key away.

  • Cached on disk, so the idle screen never waits on the network twice.
  • Keyword driven, and it can be switched off completely with one option.
  • The next photo is fetched with Ctrl+Shift+K.

script-opts / bg.conf

# keywords are comma separated
keywords=nature,landscape,minimal,city,night
# leave empty for a random photo
cache_dir=~~/cache/bg
bg.lua Fetches, caches and paints the background.

Deep dive 02

Double-click to resume

Closing mpv and coming back later should not mean finding the file again. The double click on the window reopens the last media and resumes it at the exact position it was left at, and the saved position deliberately ignores stray volume and mute changes.

  • A deliberately narrow list of what is restored: start, speed, pitch, tracks, delay and scale.
  • No modification time check, so remote files keep their saved position.
  • Fullscreen moved to f so the double click is free.

config / mpv.conf

save-position-on-quit=yes
resume-playback=yes
resume-playback-check-mtime=no
write-filename-in-watch-later-config=yes
watch-later-options=start,speed,pitch,aid,sid,sub-delay,sub-scale
lasthit.lua Reopens the last file on a double click.

Deep dive 03

YouTube, as a real client

The format menu lists the formats the server actually offers and switches between them without reloading the video. The subtitle menu lists every language the video carries, creator uploaded and auto generated, with a separate track for the secondary language.

  • Creator subtitles are pre-loaded as normal tracks, so the usual key still works.
  • Sponsor segments can be skipped, and the category list is configurable.
  • The stream you are watching can be downloaded at the quality mpv negotiated.

config / mpv.conf

ytdl-raw-options=sub-langs=(en|ja|de|es|fr|it|ru|pt|pl|nl|sv|tr|ko|zh).*,js-runtimes=node

The JavaScript runtime line is not optional. Without a named runtime, modern yt-dlp cannot solve the signature challenges and every video comes back without usable formats.

quality-menu.lua ytsubs.lua sponsorblock_minimal.lua

Deep dive 04

A subtitle pipeline, not a font size

Subtitles are set in Geist Medium at 40, in a warm off-white, with a hairline outline and a soft shadow so they survive any background. Margins are forced so a 2.35 to 1 film keeps its captions inside the letterbox instead of floating over the image.

  • Fansub ASS files get a gentle restyle so they match plain text subtitles.
  • Two opt-in looks: a translucent panel and shadow-only cinema subtitles.
  • Bitmap subtitles are softened rather than restyled.

config / conf / subtitles.conf

sub-font=Geist Medium
sub-font-size=40
sub-color=FCF3E8
sub-border-size=1.2
sub-shadow-size=1.6
sub-ass-force-margins=yes

Deep dive 05

Hardware decode, then Anime4K

d3d11 output with d3d11va decoding is the single biggest win on an integrated GPU with shared memory. On top of that sits the full quality stack: EWA Lanczos for luma, spline36 for chroma, mitchell for downscaling, and anti-ringing so the sharpening does not ring.

  • Anime4K line-art restoration applies itself to files whose path contains anime.
  • The shader cache is built ahead of time, so the first play does not stutter.
  • Vulkan output is one key away for an A and B comparison.

config / conf / video.conf

vo=gpu-next
gpu-api=d3d11
gpu-decoder=d3d11va
scale=luma:ewa_lanczos
scale-chroma=spline36
dscale=mitchell
dither=fruit
tone-mapping=spline
Alt+0 Alt+2 Alt+4

Deep dive 06

Controls that hover, then get out of the way

The control bar and the timeline are translucent and stay on screen while the picture plays, but the overlays are pointer driven: they appear where the mouse is and fade away when it leaves. A speed meter with a spring needle sits at the centre of the screen while the speed changes.

  • Centred seek, volume and speed overlays, drawn by the skin rather than by the player.
  • Seekbar thumbnails are pre-fetched while the pointer moves.
  • An info button opens the player statistics: codec, frames per second, bitrate, dropped frames.

config / mpv.conf

# the skin draws the controls, so mpv's own is off
osc=no
osd-bar=no
# keep the window interactive after a file ends
keep-open=yes
keep-open-pause=yes
